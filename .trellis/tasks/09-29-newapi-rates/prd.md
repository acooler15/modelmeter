# New API 模型费率

## Goal

P1-5:对接 New API(one-api 系)网关拉取模型倍率 / 价格表并展示;模型测试时按费率估算单次调用成本。

## Requirements

### New API 配置

1. 配置项:网关地址(Base URL)+ 访问令牌(管理 token),存 settings 表(键 `newapi`,见父任务 design.md);界面可保存、修改。
2. 令牌脱敏展示(复用统一脱敏规则)、不写日志;GET 配置接口只返回脱敏值,PUT 留空沿用原值。

### 费率拉取与展示

3. `GET /api/newapi/rates`:后端调 New API 的定价接口(优先 `{base}/api/pricing`,实现时以真实接口校准),解析模型名、倍率(输入/完成)、按次价格等字段并返回;不落库(每次实时拉取)。
4. 前端「模型费率」页(`/rates`):配置卡片(地址 + 令牌 + 保存)+ 费率表格(模型、计费类型、输入倍率、完成倍率、价格),支持关键字过滤;未配置时中文引导。
5. 错误中文提示并区分:配置不完整(3401)、网络错误(3500)、鉴权失败(3501)、响应异常(3502)。

### 成本估算

6. 模型测试完成后,若 New API 已配置且测试所用模型命中费率表,按 usage 与费率估算单次成本并展示在结果区(注明估算口径);未命中或未配置时不显示、不报错。
7. 计费口径(实现时按 one-api/New API 实际返回校准):
   - 倍率型:`quota = 输入倍率 × prompt_tokens + 输入倍率 × 完成倍率 × completion_tokens`
   - 按次型:固定价格/次
   - 换算展示:quota → 美元(按 New API 约定汇率)与人民币可选;界面注明「估算值」。

### 非功能

8. 请求全部后端代理;全中文界面。
9. `go vet` / `go test`;`npm run lint` / `npm run build` 通过。

## Acceptance Criteria

- [ ] 配置地址与令牌后可拉取并展示费率表,过滤可用
- [ ] 未配置 / 配置不完整 / 网络失败 / 鉴权失败各有明确中文提示
- [ ] 令牌界面脱敏、不进日志;GET 不回明文,PUT 留空沿用
- [ ] 测试页对命中费率的模型显示单次成本估算,未命中不干扰
- [ ] 服务重启后 New API 配置仍在(settings 表)
- [ ] 检查命令全部通过(同上)

## Notes

- New API 定价接口字段以实现时真实接口为准,允许解析器对字段缺失降级(仅展示可解析部分)。
- 本任务不改测试页的测试逻辑,只在结果展示层挂成本估算。
